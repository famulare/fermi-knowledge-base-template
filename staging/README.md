# Staging

Drop zone for files awaiting ingest.

## How to Use

1. Place files here that you want to add to the KB
2. Tell Fermi: "Ingest the file in staging/"
3. Fermi will determine the appropriate workflow and process it
4. The staging copy is removed after successful ingest

## Supported File Types

- PDFs, images, data files (CSV, JSON)
- Text documents, markdown notes
- Any file type supported by INGEST_FILE workflow
