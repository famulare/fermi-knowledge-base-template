# Meta Layer

The meta layer organizes raw material into interpretive structure. This is where understanding is built.

## Principles

- **Traceable** — all content links back to raw sources
- **Origin-labeled** — every non-trivial idea carries provenance
- **Editable** — can be revised, superseded, or synthesized
- **Git-auditable** — all changes tracked

## Directory Structure

- `claims/` — Falsifiable statements with evidence
- `models/` — Mechanistic explanations and frameworks
- `maps/` — Conceptual domain overviews
- `contradictions/` — Documented tensions between claims/models
- `timelines/` — Evolution of understanding on specific topics

## Templates

Each directory contains a `_template.md` with the required structure for entries.

## Status Taxonomy

| Status | Meaning |
|--------|---------|
| Draft | Work in progress |
| Active | Current working understanding |
| Exploratory | Speculative or night-science |
| Reflection | Meta-observation about the work |
| Superseded | Replaced by newer understanding |
| Archived | No longer actively relevant |
