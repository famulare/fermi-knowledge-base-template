# Index Layer

Retrieval infrastructure for the knowledge base.

## Files

- `tags.md` — High-signal topical tags (prefer few, meaningful tags)
- `entities.md` — Named entities with aliases
- `link_graph.md` — Structural relationships between KB elements
- `glossary.md` — Definitions of key terms

## Principles

- Fermi owns tagging and linking decisions
- Prefer few, high-signal tags over exhaustive categorization
- Links only when structurally meaningful
- Entity registry with aliases for consistent reference
