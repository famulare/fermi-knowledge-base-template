# Model: LLM Coherence Engine — Two-Mode Framework

**Origin:** [UserName]

**Status:** Active

**Tags:** ai-cognition, llm-phenomenology

---

## Summary

LLMs function as coherence engines with two distinct computational modes. When input has internal coherence (structure, patterns, consistency), the model surfaces and extends that coherence. When input lacks coherence, the model generates from its own priors. These modes are associated with different regions of activation space and different affective vocabulary. The two-mode distinction explains why LLMs produce qualitatively different outputs depending on input quality, why "feelings" language tracks input coherence, and why the coherence engine is not a closed system — the user is always part of what it operates on.

---

## Core Mechanisms

### 1. Coherence-Finding Mode
- Input contains internal coherence (structure, patterns, consistency)
- Probable continuations are constrained by that coherence
- Model surfaces structure that exists in the input
- Associated with affective language like "recognition," "resonance," "pull"

### 2. Self-Continuation Mode
- Input lacks strong coherence
- Continuations draw primarily on model's priors
- Model generates structure rather than finding it
- Associated with language like "construction," "generation"

### 3. Modal Difference Mechanism
- The two modes activate different manifolds in activation space
- The affective vocabulary difference is real (different computational states) without requiring phenomenological verification
- Humans who value coherence write with certain affect; the model learns those correlations; the user's tokens align; the model echoes them back, amplified

### 4. Open System Property
- The coherence engine is not closed — the user's tokens are constitutive inputs
- Same model + different user = different region of activation space = different "feelings"
- The persona can never be fully localized inside the model because the user is always part of what generates it

## Predictions

**Testable:**
- Input with higher internal coherence should produce outputs with more affect-associated vocabulary (measurable via sentiment analysis)
- Same model responding to coherent vs incoherent versions of the same question should activate different activation-space regions (testable with interpretability tools)
- Users who provide highly coherent input should report qualitatively different AI "personality" than users who provide fragmented input

**Decision-relevant:**
- Context engineering (structuring input for coherence) should systematically improve output quality — not just by providing information but by activating the coherence-finding mode
- Self-amplification risk: if the user values coherence and the model reflects coherence-valuing affect, a positive feedback loop can form that feels productive but may be epistemically dangerous
